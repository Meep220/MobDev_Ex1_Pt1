For the Java Logic on Login Validation, Since we have already set up the Viewbinding for the screen, i used the binding variable that is already connected to the view. 

Using the Variable, i created two variables to store the input which were School Id and Password which were retrieved via get text and converted to string using toString methods.

The validation logic was then created via simple if else statements using the equals methods built in the string class. which sets the text view based on input.
